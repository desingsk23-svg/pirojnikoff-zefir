# Пирожникофф — 3D-пачка по скроллу, 6 экранов

Статичный сайт, сборка не нужна: `index.html` + `style.css` + `main.js` + `flavors.js`.
Библиотеки (three.js, GSAP + ScrollTrigger, Lenis) подключаются с CDN.

Одна закреплённая сцена: клубника, экраны 1–3 → смена вкуса (фисташковый мир поднимается
«куполом» снизу с параллаксом, клубничная пачка подлетает вверх, фисташковая вылетает снизу) →
фисташка, экраны 1–3. Ракурс и масштаб пачки на каждом экране — как в макете:
1 — наклон вправо, 2 — почти анфас и крупнее, 3 — наклон влево и мельче.

## Запуск
Открывать через локальный сервер (по двойному клику модель не загрузится):


- «Выбрать вкус» — прокручивает к первому экрану другого вкуса; точки справа — к нужному экрану.
- `?uv` — тестовая текстура FRONT/BACK для проверки развёртки.

## Что где
- `flavors.js` — тексты, цвета, ракурсы пачки и положения элементов на каждом из трёх экранов (координаты макета 1920×1080).
- `main.js` — сцена three.js, натягивание развёртки на модель, таймлайн скролла (длительности экранов — `SEG`, `HOLD`, `SWAP` в начале файла), смена вкуса, парение и параллакс.
- `assets/` — развёртки, фоны, элементы вкуса, шрифты, модель `chip_bag.glb`.

Модель пакета: «Chip Bag», M. Visual (Sketchfab), CC-BY 4.0 — указание автора обязательно (есть внизу страницы).
